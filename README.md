# Estudos de Data Science

Material prático de Python e R para análise, limpeza e visualização de dados.

- `Py/`: fundamentos de Python, NumPy, pandas, matplotlib e seaborn.
- `R/`: fundamentos de R, importação, tratamento e visualização.
- `Conteudos/`: notebooks complementares.

## Python

```bash
python -m venv .venv
python -m pip install -r requirements.txt
jupyter lab
```

## R

Os arquivos R Markdown usam principalmente `lattice`, `readxl`, `RColorBrewer` e
`stargazer`. Instale esses pacotes no R antes de renderizar os documentos.
